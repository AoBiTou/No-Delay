# 绝不拖延 / NO DELAY

一个帮助用户从“我要做”快速进入“我正在做”的本地优先专注网站。

## 第一版已实现

- 十次点击劈砖启动仪式，包含裂纹、震屏、碎片和动态文字
- 今日任务：新增、编辑、删除、完成、优先级、时间和预计时长
- 自动推荐当前最应该开始的任务
- 今日 / 本周 / 全部日程视图
- 可靠的专注与休息计时：基于时间戳，不受标签页降频影响
- 暂停、继续、放弃、再来一轮与休息流程
- 专注历史与今日统计
- 25/5、45/10、60/20、90/30 和自定义节奏
- 浏览器本地持久化，无需登录
- 桌面与移动端响应式布局

## 启动

```bash
pnpm install
pnpm dev
```

然后打开 `http://localhost:3000`。

## 检查

```bash
pnpm lint
pnpm typecheck
pnpm build
```

## 数据说明

任务、设置、专注记录和进行中的计时保存在浏览器 `localStorage` 中。启动仪式的本次完成状态保存在 `sessionStorage` 中，关闭标签页后会在新会话再次出现。

项目没有后端 API，也不会把任务、专注记录或设置上传到服务器。生产响应包含 CSP、禁止嵌入、权限限制、Referrer Policy、HSTS 和 MIME 嗅探防护等安全头。
